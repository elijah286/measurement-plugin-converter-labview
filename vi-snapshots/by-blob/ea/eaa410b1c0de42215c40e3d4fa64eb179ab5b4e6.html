    Channel Name specifies which output channel to use.

    Current Limit specifies the current limit on the specified channel(s).

    Voltage Level Start specifies the voltage level, in volts, for the output channel generation.

    Voltage Level Stop specifies the voltage level, in volts, for the output channel generation.

    Each plot will configure points on the device with voltage between the start and stop voltage.
