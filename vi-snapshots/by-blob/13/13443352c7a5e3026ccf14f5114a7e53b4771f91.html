Line-Load Regulation.vi

Demonstrates how to set up a hardware-timed two-channel nested voltage sweep and display the results in a graph (IV Curve). Use this example to produce the characteristic curves of a FET transistor. It can be easily adapted to test a BJT by performing a current sweep instead of a voltage sweep. This example performs a hardware-timed sweep (with triggers and events) using Sequence source mode.

[Source device source delay (s)]

Source Delay determines when, in seconds, the device generates the Source Complete event, potentially starting a measurement if the Measure When property is set to Automatically After Source Complete.

This is intended to allow the output to settle before taking the measurement.

Source Delay determines when, in seconds, the device generates the Source Complete event, potentially starting a measurement if the Measure When property is set to Automatically After Source Complete.

Timeout (Sec) specifies the maximum time allowed for this VI to complete in seconds. If the VI does not complete within this time interval, an error will be returned.
