Calculate_SNR_THD.vi

Finds the fundamental and harmonic components (amplitude and frequency) present in the input Auto Power Spectrum, and computes the %THD and the %THD plus noise.

NOTE: You must pass the windowed auto power spectrum of your signal to this VI for it to function correctly. You should pass your time-domain signal through the Scaled Time Domain Window and then through the Auto Power Spectrum, connecting the Auto Power Spectrum to this VI.

Inputs

-----------

Auto Power Spectrum

is the single-sided auto power spectrum of the windowed signal. This array can be the output of a frequency-domain averaging process for improved harmonic estimation.

frame size

is the number of samples in the original signal. Normally the frame size is the number of samples in one block of data from a data acquisition.

# harmonics

is the number of harmonic components that you want this VI to approximate and use in the harmonic analysis and THD measurement. This number includes the fundamental component. For example, if you wanted to compute the second harmonic distortion in your signal, this number should be two (find the fundamental frequency component (say, at f1 Hz) and its second harmonic (at f2 = 2f1 Hz).

window

is the window selection that you used for the Scaled Time Domain Window VI. If no window function was used (not recommended for an accurate THD estimation), this selector defaults to 0 (no window).

sampling rate

is the input sampling rate in Hz.

fundamental frequency

is an estimate of the fundamental frequency that you want this VI to use in the harmonic search and in the THD computation. If this control is set to zero (default), then the non-DC component with the maximum magnitude found in Auto Power Spectrum will be used as the fundamental component.

Outputs

-----------

Harmonic Amplitudes

is the array of amplitudes of the fundamental component and its harmonics. These values are always positive and are in units of Vrms if the input Auto Power Spectrum values are given in Vrms^2.

Harmonic Frequencies

is the array of frequencies of the fundamental component and its harmonics. These value are in units of Hz if the input sampling rate is given in Hz.

% THD

is the percent total harmonic distortion present in the input Auto Power Spectrum. The THD computation is computed using:

% THD = 100 * sqrt[A(f2)^2 + A(f3)^2 + ... + A(fN^2)] / A(f1)

where

A(f1) is the amplitude of the fundamental component

A(fN) is the amplitude of the Nth harmonic

N is the # harmonics

% THD + Noise

is the percent total harmonic distortion plus noise present in the input Auto Power Spectrum. % THD + Noise is computed using:

% THD + Noise = 100 * sqrt[sum(APS)] / A(f1)

where

sum(APS) is the sum of the Auto Power Spectrum without the power near DC and near the fundamental.
