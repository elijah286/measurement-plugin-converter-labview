Agilent N6700 Series Configure Histogram.vi

Configure the histogram, histogram trigger source, initiates the histogram, triggers the histogram and fetches the histogram bin data.

<b>Note:</b>

This VI only applies to the N6705B and N6705C DC Power Analyzer.

Connector Pane

Front Panel

Controls and Indicators

 Agilent SMU

A unique reference to an instrument I/O session. It identifies which device to communicate with and all configuration information to perform the I/O. See the initialize VI for more information.

Channel Name

Pass the name of the channel on which to fetch the peak to peak value of the data logger.

Valid Channel Names: 1,2,3,4

Default Value: 1

Bin Range (0: 8 A)

There are two bin ranges, with 4096 bins in each of the ranges.

Valid Values:

8 A - The 8 A range has 4096 bins with minimum and maximum bin amplitudes of -8A and +8A and a bin size of 3.9mA (16 / 4096).

0.0039 A - The 0.0039 A range has 4096 bins with minimum and maximum bin amplitudes of -3.9mA and +3.9ma and a bin size of 1.9uA (7.8ma / 4096).

Default Value: 0: 8 A

Histogram Range

Selects the current histogram measurement range. The value that you enter must be the highest value in amperes that you expect to measure.

Units: amps

Valid Range:

-3.0 to +3.0 A

Default Value: 0.0

Histogram Trigger Source

Selects the trigger source for the histogram measurement data logger.

Valid Values:

0: External - Selects the rear panel Trigger In BNC connector.

1: Software - Selects a remote interface trigger command.

2: Immediate - The power supply triggers the histogram measurement data logger immediately.

3: Pin 1 - Selects an output port connector pin 1.

4: Pin 2 - Selects an output port connector pin 2.

5: Pin 3 - Selects an output port connector pin 3.

6: Pin 4 - Selects an output port connector pin 4.

7: Pin 5 - Selects an output port connector pin 5.

8: Pin 6 - Selects an output port connector pin 6.

9: Pin 7 - Selects an output port connector pin 7.

Default Value: 1: Software

<b>Note:</b>

PIN<1-7> must be configured as trigger input before it can be used as a trigger source. See Pin Functions and Polarity in <b>Configure Pin.vi</b>.
