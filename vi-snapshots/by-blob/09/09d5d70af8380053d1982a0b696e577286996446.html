Take fron panel screenshot.vi

This example captures an image of the front panel of a VI and saves the image to a JPG, PNG, or BMP file.

Connector Pane

Front Panel

Controls and Indicators

 File type (.jpg)

The type of image file to be saved (JPEG, PNG, or bitmap)

Image path

image path specifies the path to and name of the image file to create

Visible area only? (f)

If true, only the portion of the front panel that is visible will be captured (determined by the size of the front panel window). If false, the captured image will be as small as possible while still containing all controls and indicators.

If the VI path indicates a VI that is not open, the image captured will have the same dimensions as the front panel the last time it was saved (regardless of the visible area only? state).

error in (no error)

The error in cluster can accept error information wired from VIs previously called. Use this information to decide if any functionality should be bypassed in the event of errors from other VIs.

The pop-up option Explain Error (or Explain Warning) gives more information about the error displayed.
