Front Panel

Controls and Indicators

 Measurement Function (10: Voltage DC)

Specifies the measurement function.

Valid Values:

0 - Continuity

1 - Current AC

2 - Current DC

3 - Diode

4 - Frequency

5 - Resistance 4-wire

6 - Period

7 - Resistance 2-wire

8 - Temperature

9 - Voltage AC

10 - Voltage DC

11 - Voltage DC Ratio

Default Value:

10 - Voltage DC

Timeout (10000 ms)

The maximum length of time, in milliseconds, in which to allow the multipoint read operation to complete.

Valid Range:

0 - 4,294,967,295 ms

Sample Count (1)

The number of measurements the DMM takes each time it receives a trigger.

Valid Range:

1 to 1000000

Default Value:

1

VISA resource name

Specifies which instrument to use. Instruments that are powered on and connected to your computer are visible in the VISA resource name pull-down menu. Select the resource name from the VISA resource name pull-down menu. If your instrument does not appear in this list, enter the instrument descriptor using the following format:

Interface Type[board index]::Address::INSTR.

Examples:

GPIB: GPIB::22::INSTR, GPIB board 0, primary address 22

TCP/IP Instr: TCPIP::10.0.32.48::INSTR

USB Instr: Selectable from VISA Resource Name pull-down menu

VISA Alias: "SampleInstr" - Alias names are configured in MAX

Refer to the LabVIEW Help for more information about specifying a VISA resource name.

error in (no error)

error in can accept error information wired from VIs previously called. Use this information to decide if any functionality should be bypassed in the event of errors from other VIs.

Right-click the error in control on the front panel and select Explain Error or Explain Warning from the shortcut menu for more information about the error.

NPLC(10PLC)

Specifies the integration time in seconds (called aperture time) for measurements.

Valid Range:

0.0002 s to 1 s

Default Value:

.1s

Note(s):

(1) Applies only to the 34465A and 34470A.

(2) Aperature supports all Measurement Functions
