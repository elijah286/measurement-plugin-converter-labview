Shows how to configure a measurement and take multiple readings.

Controls and Indicators

 VISA resource name

A reference to the instrument in use. The reference to the resource name is created in the Initialize VI. Therefore, before calling this VI, you need to call the Initialize VI. To run this VI interactively, select the previously initialized resource name from the pull-down menu. To run this VI programmatically, wire the VISA resource name out terminal of the Initialize VI to subsequent VISA resource name input terminals. You chain instrument driver VIs together by wiring the VISA resource name out terminal to subsequent VISA resource name input terminals.

Function (0: DC Voltage)

Sets the measurement function on the instrument.

Manual Resolution (2: 6.5 digits)

Sets the measurement resolution on the instrument. Note that not all functions can display 8.5 digits of resolution for instance ACV can only go up to 6.5 digits regardless of whether you choose 8.5 digits. Also note that the higher the resolution, the slower the instrument will be in taking measurements.

Valid Range:4.5 - 8.5

Trigger Type (0:Auto)

This sets the trigger that indicates what condition will cause the instrument to start taking samples.

Frequency Source (3: AC Voltage)

Specifies the source whose frequency will be calculated. This applies only the the Frequency and Period Function.

Auto Range (1:ON)

Sets the DMM Auto Range Function

Sample Count (1)

The number of measurements the DMM takes each time it receives a trigger.

Valid Range:1 to 16777215

Maximum Time (10000 ms)

The maximum length of time in which to allow the multi-point read operation to complete. Express this value in milliseconds.

Valid Range:

0 to 4,294,967,295 ms

Note:

For a large number of samples, the timeout must be increased to prevent the instrument driver's VISA session from ending early. If the timeout is too short the instrument may return a "query unterminated" error.

Trigger Count (1)

The number of triggers the DMM receives before returning to the idle state. For each trigger received, a specified amount of samples is taken.

Range: 0 - 2.1E9

Manual Range (1.00)

Sets the range to use on the instrument. Set this to the absolute value of the upper bound of the expected reading and the instrument adjusts to the most sensitive settings value.

Valid Range:

For DCV,ACV,ACDCV,DSAC,DSDC,SSAC,SSDC: -1 to 1E3

For OHM,OHMF: -1 to 1.2E9

For DCI,ACI,ACDCI: -1 to 1.2

Note:

(1) This control is only valid if Auto Range is set to Off

(2) Setting manual range can improve performance.

(3) Measurements above the manual range value will be returned as out of range.

(4) -1 specifies Auto Range.

Integration Time (0 PLCs)

This sets the integration time of the DMM. The greater the integration time, the slower and more accurate the data acquisition will be. Note that a value of 0 gives the fastest measurements with the lowest accuracy, lowest resolution and no NMR. A value of 1000 gives the most accuracy, highest resolution and 80dB of NMR with slowest measurement speed.

Range: 0 to 1000 PLCs
