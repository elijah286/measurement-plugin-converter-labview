Load and Vin SMU Measurement.vi

Demonstrates how to use the DC Voltage Output Function to force an output voltage. This example initializes a session, configures the Output Function, Sense, Autorange, Voltage Level and Current Limit, initiates generation, waits for a specified delay, and measures the voltage and current output. This example uses Single Point source mode.
