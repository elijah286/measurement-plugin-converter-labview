Efficiency.vi

Demonstrates how to use triggers and events to synchronize multiple channels in Sequence source mode. Use this example to sequence multiple channels in lock-step.

 [Source device name]

Resource Name specifies the resource name assigned by Measurement & Automation Explorer (MAX), for example, PXI1Slot3, where PXI1Slot3 is an instrument resource name. resource name can also be a logical IVI name.

[Current load level start]

Voltage Level Start specifies the voltage level, in volts, for the output channel generation.

Each plot will configure points on the device with voltage between the start and stop voltage.

Source Delay determines when, in seconds, the device generates the Source Complete event, potentially starting a measurement if the Measure When property is set to Automatically After Source Complete.

This is intended to allow the output to settle before taking the measurement.
