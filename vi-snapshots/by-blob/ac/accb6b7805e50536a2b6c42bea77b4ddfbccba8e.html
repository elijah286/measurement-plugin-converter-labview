Agilent 34401 Acquire and Chart - External Triggered.vi

This example shows how to configure an externally triggered measurement using the low-level Data VIs to retrieve data from the DMM.

Note:

(1) It is recommended that all triggered measurements be made using an appropriate fixed manual range. That is, disable autorange and manually select a range in Configure Measurement VI.

(2) To increase the speed of DC measurements, set Autozero to "once," or "off" in Configure Autozero VI.

(3) For faster AC measurements, call the Configure AC Filter VI to set the AC filter to 200 Hz, and set the manual trigger delay to 0 seconds in Configure Trigger VI.

 VISA resource name

Specifies which instrument to use. Instruments that are powered on and connected to your computer are visible in the VISA resource name pull-down menu. Select the resource name from the VISA resource name pull-down menu. If your instrument does not appear in this list, enter the instrument descriptor using the following format:

Interface Type[board index]::Address::INSTR.

GPIB: GPIB::22::INSTR, GPIB board 0, primary address 22

Serial: COM1

TCP/IP Instr: TCPIP::10.0.32.48::INSTR

USB Instr: selectable from VISA Resource Name pull-down menu

USB Raw: You must first link VISA to non-USBTMC instruments by using the VISA Driver Development Wizard

VISA Alias: "SampleInstr" - Alias names are configured in MAX

Refer to LabVIEW online help for more information on specifying a VISA resource name.

Trigger Count (5)

The number of triggers the instrument receives before returning to the idle state.

Valid Range:

Agilent 34401: 1 to 50000 (instrument can only hold 512 readings internally)

Agilent 34410: 1 to 50000

Agilent 34411: 1 to 1000000

Samples per Trigger (10)

The number of measurements the instrument takes each time it receives a trigger.

Valid Range:

Agilent 34401: 1 to 50000 per trigger (instrument can only hold 512 readings internally)

Agilent 34410: 1 to 50000 per trigger

Agilent 34411: 1 to 1000000 per trigger

Enable Auto Delay (T: Enable)

Enables or disables automatic trigger delay. If this control is set to False, the "Manual Trigger Delay" control sets the specific trigger delay value.

Manual Trigger Delay (0.0 s)

This value sets the delay time between the trigger signal and each sample that follows. AC measurements performance can be improved by using a small trigger delay.

Valid Range:

0 to 3600 seconds. The default trigger delay is automatic; the delay is determined by function, range, integration time, and ac filter settings.

Default Value:

0.0

Note:

This control is only valid if "Enable Auto Delay" is set to "False".

Enable Auto Range (F: Disable)

Enables or disables automatic range selection on the instrument.

Note:

(1) If this control is set to False, the Manual Range and Manual Resolution settings are used.

(2) It is recommended that Auto Range be disabled for all triggered measurements.

Manual Range (1.00)

Sets the range to use on the instrument. Sets the range to use on the instrument. When you set this control to the absolute value of the upper bound of the expected reading, the instrument adjusts to the most sensitive settings that can measure that value. For instance, if you expect a reading of 50mV (.05V), set this control to 0.1 as shown below in the valid ranges for DC Voltage. The VI rounds up to the next range any values between these ranges. The VI selects the largest range if you enter a value larger than the largest range.

Valid Ranges:

AC/DC Voltage

All models: 100m, 1, 10, 100, 1k

2/4 Wire Resistance

Agilent 34401: 100, 1k, 10k, 100k, 1M, 10M, 100M

Agilent 34410/34411: 100, 1k, 10k, 100k, 1M, 10M, 100M, 1G

DC Current

Agilent 34401: 10m, 100m, 1, 3

Agilent 34410/34411: 100u, 1m, 10m, 100m, 1, 3

AC Current

Agilent 34401: 1, 3

Agilent 34410/34411: 100u, 1m, 10m, 100m, 1, 3

Capacitance

Agilent 34410/34411 only: 1n, 10n, 100n, 1u, 10u

Note:

(1) Setting manual range can improve performance.

(2) Measurements above the manual range value will be returned as out of range.

(3) This control is only valid if Enable Auto Range is set to False

Stop

Stops the acquisition.

Timeout (10000 ms)

The maximum length of time in which to allow the multi-point read operation to complete. Express this value in milliseconds.

Valid Range:

0 to 4,294,967,295 ms

Note:

For a large number of samples, the timeout must be increased to prevent the instrument driver's VISA session from ending early. If the timeout is too short the instrument may return a "query unterminated" error.

Function (0: DC Voltage)

Sets the measurement function on the instrument.

Valid Values:

0: DC Voltage

1: AC Voltage

2: 2 - Wire Resistance

3: 4 - Wire Resistance

4: DC Current

5: AC Current

6: Frequency

7: Period

8: Continuity

9: Diode Checking

10: VDC:VDC Ratio

11: Temperature

12: Capacitance

Default Value:

0: DC Voltage

Note:

Agilent 34401 does not support temperature or capacitance configurations or measurements.

Agilent 34410/34411 does not support VDC ratio configurations or measurements.

Slope (0: Negative)

Selects whether the instrument uses 1) the rising or falling edge of the trigger signal on the rear-panel Ext Trig BNC connector. 2) the rising or falling edge with an internal trigger source.

Valid Values:

0: Negative

1: Positive

Default Value:

0: Negative

Note:

1) This control only applies to the Agilent 34410/34411 models.

2) This control only applies to internal and external trigger sources.

error in

error in is a cluster that describes the error status before this VI executes. If error in indicates that an error occurred before this VI was called, this VI may choose not to execute its function, but just pass the error through to its error out cluster. If no error has occurred, then this VI executes normally and sets its own error status in error out. Use the error handler VIs to look up the error code and to display the corresponding error message. Using error in and error out clusters is a convenient way to check errors and to specify execution order by wiring the error output from one subVI to the error input of the next.
