 Standard Waveform Configuration

Configuration Parameters for the standard waveform.

Note:

Set the duty cycle percentage for square waves. The duty cycle setting is remembered when you change from square wave to another function. When you return to the square wave function, the previous duty cycle is used.

Limits Due to Frequency

If the square wave function is selected and

you change to a frequency that cannot produce the current duty cycle, the duty cycle is automatically adjusted to the maximum value for the new frequency.

Max Duty Cycle

20% to 80% (frequency < 25 MHz)

40% to 60% (25 MHz < frequency < 50 MHz)

50% (frequency > 50 MHz)

Max Duty Cycle (For 33120 Only)

20% to 80%, in 1% increments (frequency  5 MHz).

40% to 60%, in 1% increments (frequency > 5 MHz).

    		DC Offset (V)

    The DC offset of the standard waveform you want the function generator to produce. This value is the offset at the output terminal.

    Default Value: 0.00 V

    		Unit

    Sets the amplitude unit.

    Valid Range:

    0 - Vpp

    1 - Vrms

    2 - dBm

    Default Value: Vpp

    		[Amplitude (V)]

    The amplitude of the standard waveform you want the function generator to produce. This value is the amplitude at the output terminal.

    Valid Range:

    Model 33120A:

    0.05 - 10.00 (Vpp) (50 Ohm impedance)

    0.10 - 20.00 (Vpp) (Infinite impedance)

    Model 33210A, 33220A and 33250A:

    0.001 - 10.00 (Vpp) (50 Ohm impedance)

    0.002 - 20.00 (Vpp) (Infinite impedance)

    Default Value: 1

    		Duty cycle (%)

    Determines the duty cycle for the generated waveform. Applies only to pulse wave.

    Range: 0.002....99.998

    Duty Cycle Limitations: For square waveforms, the function generator may not be able to use the full range of duty cycle values at higher frequencies as shown below.

    20% to 80% (frequency < 25 MHz)

    40% to 60% (25 MHz < frequency < 50 MHz)

    50% (frequency > 50 MHz)

    Default: 50

    Unit: %

Instrument Address

(string)

A string that uniquely identifies the instrument to open or initialize. The grammar for the instrument tag is shown below. Parameters are shown in lower-case and optional parameters are shown in square brackets ([]).

GPIB - GPIB[bd]::prim addr[::sec addr]

Default Value: GPIB::1

Parameters (default value): GPIB::1

bd - GPIB board (0)

prim addr - GPIB primary address (1)

sec addr - GPIB secondary address (none)

error in

The error in cluster can accept error information wired from VIs previously called. Use this information to decide if any functionality should be bypassed in the event of errors from other VIs.

The pop-up option Explain Error (or Explain Warning) gives more information about the error displayed.

    		status

    The status boolean is either TRUE (X) for an error, or FALSE (checkmark) for no error or a warning.

    The pop-up option Explain Error (or Explain Warning) gives more information about the error displayed.

    		code

    The code input identifies the error or warning.

    The pop-up option Explain Error (or Explain Warning) gives more information about the error displayed.

    		source

    The source string describes the origin of the error or warning.

    The pop-up option Explain Error (or Explain Warning) gives more information about the error displayed.
