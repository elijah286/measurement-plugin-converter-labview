PCM data configuration

PCM data configuration specifies the data format (bits arrangement) in a single Frame Sync Clock cycle.

    		Frame Sync Edge for Channel 0

    Frame Sync Edge for Channel 0 specifies if channel 0 starts after the Rising or Falling edge of the Frame Sync Clock.

    		Channel Count Per Frame

    Channel Count Per Frame specifies the number of channels within a frame.

    		Channel Length

    Channel Length specifies the number of bits for a channel within a frame.

    		Bit Depth

    Bit Depth(also known as Audio Depth) specifies the number of bits that function as a sample. The value of Bit Depth must be smaller than or equal to the value of **Channel Length**. A smaller **Bit Depth** value indicates that, within a channel, some bits function as a sample while the remining bits are forced to 0.

    		Channel 0 Offset

    Channel 0 Offset specifies the number of bits for which Channel 0 of a frame has to wait before transmitting or receiving data after the frame starts. The first bit of Channel 0 starts after 1-bit delay in I2S data format and without any delay in most of other data formats.

    		Endianness

    Endianness specifies the order in which data bits are received. Possible values are MSB First and LSB First. If this option is set to MSB First, the most significant bit (MSB) is received first. If LSB First, the least significant bit (LSB) is received first.

    		Data Justification

    Data Justification specifies the location where data is received within a channel or slot. Possible values are Left Justified and Right Justified. This option does not take effect if Bit Depth is equal to Channel Length.

Frame Sync Clock Control

frame size specifies the expected characteristics of the input Frame Sync Clock(Word Select/WS).

    		Frame Length

    Frame Length specifies the number of Bit Clock cycles or bits within a cycle of the Frame Sync Clock.

    This property defines the sampling rate Fs = Bit Clock rate / Frame Length.

    		Frame Sync Pulse Width

    Frame Sync Pulse Width specifies the number of bits or Bit Clock cycles for which the Frame Sync Clock stays high within a Frame Sync Clock cycle. Most cases, the Frame Sync Clock (Word Select) is of 50% duty cycle. So, Frame Sync Pulse Width = Frame Length/2. But for some data formats, this might be different.

    		Bit Clock Edge Sync

    Bit Clock Edge Sync specifies if the Rising or Falling edge of the Bit Clock aligns with the Frame Sync Clock edge.

error out

error in can accept error information wired from VIs previously called. Use this information to decide if any functionality should be bypassed in the event of errors from other VIs.

Right-click the error in control on the front panel and select Explain Error or Explain Warning from the shortcut menu for more information about the error.

    		status

    status is TRUE (X) if an error occurred or FALSE (checkmark) to indicate a warning or that no error occurred.

    Right-click the error in control on the front panel and select Explain Error or Explain Warning from the shortcut menu for more information about the error.
