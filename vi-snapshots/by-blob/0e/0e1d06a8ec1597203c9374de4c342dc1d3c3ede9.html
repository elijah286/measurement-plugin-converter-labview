LDO Line Regulation.lvlib:main.vi

<b>Caller</b> Information is input for framework components. Mode should be set to <b>Automation</b> when running from TestStand. Sequence Context should be set to <b>ThisContext</b> when running from TestStand. The values will be updated everytime the setting is applied using "Edit" dialog.

<b>Test Pins</b> is names of pins available in the pinmap file. Provide the right pins for the required functionality.

<b>Test Inputs</b> is input required for the measurement to perform.

<b>error in</b> is meant for the sequencing. <b>error in</b> should be <b>no error</b> always.

<b>Test Results</b> contains all the measured data during the measurement and processed results.

<b>error out</b> contains the error occured during measurement.

Check measurement documentation for more information (<Program Files>\Soliton Technologies\MeasurementSuite\CodeModules\LDO\LDO Line Regulation.pdf)
