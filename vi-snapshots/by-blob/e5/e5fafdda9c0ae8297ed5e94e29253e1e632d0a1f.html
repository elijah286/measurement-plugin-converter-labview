 Ref Waveform Type

Specifies whether the REF waveform is normal or came from a MATH.

Valid Values:

Normal (0) - The REF waveform is normal.

Came from a MATH (1) - The REF waveform came from a MATH.

Default Value:

Normal (0)

Record Length

Defines the ending point of the waveform within the waveform record in case data is irrelevant after a certain point. For example setting this value to 25 will cause the the data points after the 25th to be ignored.

Valid Range:

1 - 10000000

Default Value:

2500

Note: Values that are larger than the waveform record length will be coerced to the record length by the oscilloscope. For example the device will treat 10000000 as 10000 when the record length is 10000.

Starting Point (1)

Defines the starting point of the waveform within the waveform record in case an initial part of the waveform isn't necessary. For example setting this value to 5001 will cause the first 5000 data points to be ignored.

Valid Range:

1 - 10000000

Default Value:

1

error in (no error)

error in describes error conditions that occur before this VI or function runs. The default is no error. If an error occurred before this VI or function runs, the VI or function passes the error in value to error out. This VI or function runs normally only if no error occurred before this VI or function runs. If an error occurs while this VI or function runs, it runs normally and sets its own error status in error out. Use the Simple Error Handler or General Error Handler VIs to display the description of the error code. Use error in and error out to check errors and to specify execution order by wiring error out from one node to error in of the next node.

    		status

    status is TRUE (X) if an error occurred before this VI or function ran or FALSE (checkmark) to indicate a warning or that no error occurred before this VI or function ran. The default is FALSE.

    		code

    code is the error or warning code. The default is 0. If status is TRUE, code is a nonzero error code. If status is FALSE, code is 0 or a warning code.

    		source

    source specifies the origin of the error or warning and is, in most cases, the name of the VI or function that produced the error or warning. The default is an empty string.

VISA resource name specifies the instrument to use. Before you run this VI, run the Initialize VI to create a reference to the instrument. You then can wire that reference from the VISA resource name out output of the Initialize VI to the VISA resource name input of this VI.

level crossings

level crossings returns information about the locations of level crossings in the waveform.

    		indexes

    indexes contains the index numbers of waveform samples that fall on the crossing level and whose transition crosses both the high and low reference levels.

      		Numeric

      indexes contains the index numbers of waveform samples that fall on the crossing level and whose transition crosses both the high and low reference levels.

    		t0

    t0 returns the time at which the first sample occurred in the original waveform.

    		dt

    dt returns the time interval in seconds between the individual samples in the original waveform.

    		slope

    slope returns whether the direction of the first transition in the waveform is rising or falling

    		crossing level

    crossing level returns the input crossing level value at which the waveform falls at each sample in indexes.
