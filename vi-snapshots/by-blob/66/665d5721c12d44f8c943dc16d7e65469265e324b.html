Front Panel

Controls and Indicators

 Host Name

Name of the machine in which server is running. To use the current machine, localhost is used.

Port Number

Enter the port number of the TCP/IP connection established for the required board.

TCP port to use for the session. Allows running multiple dss instances.

Timeout (ms)

Java environment timeout. All java operations must complete within this time else a timeout error would result.

CCXML File

Target configuration file.

CCS Base Folder

Path to ccs base folder.

error in

error in can accept error information wired from VIs previously called. Use this information to decide if any functionality should be bypassed in the event of errors from other VIs.

Right-click the error in control on the front panel and select Explain Error or Explain Warning from the shortcut menu for more information about the error.

    		status

    status is TRUE (X) if an error occurred or FALSE (checkmark) to indicate a warning or that no error occurred.

    Right-click the error in control on the front panel and select Explain Error or Explain Warning from the shortcut menu for more information about the error.

    		code

    code is the error or warning code.

    Right-click the error in control on the front panel and select Explain Error or Explain Warning from the shortcut menu for more information about the error.

    		source

    source describes the origin of the error or warning.

    Right-click the error in control on the front panel and select Explain Error or Explain Warning from the shortcut menu for more information about the error.

Quiet Frame? (F)

Enable or disable java debug window frame. If frame window is enabled, on the occurrence of an exception, the contents of the window is dumped to a file.

Cpus Select[]

Defines the cpu or cpus to open session/s to. Enter 'Any Cpu' to pick the first found cpu on the configured board.

    		String

    Defines the cpu or cpus to open session/s to. Enter 'Any Cpu' to pick the first found cpu on the configured board.

Run Minimized? (F)

Decides whether to launch or minimize the command prompt while executing the batch files.

Initialize Write Cache?(T)

Decides whether to initializes the write cache or not. The write cache is flushed per core in a board.

Initialize Symbol Cache?(T)

Decides whether to initializes the symbol cache or not. The Symbol cache is flushed per core in a board.

Response From Server

Response from the server for this functions.

Pass?

Indicates the Pass/Fail status of the currently executed function.

Pass: When the function is called successfully

Fail: When the function call is unsuccessful, or if there is any error
