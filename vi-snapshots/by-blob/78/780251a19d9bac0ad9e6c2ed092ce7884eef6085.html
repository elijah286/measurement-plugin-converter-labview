Manual Range (1)

Sets the range to use on the instrument. Set this to the absolute value of the upper bound of the expected reading and the instrument adjusts to the most sensitive settings value. For instance, if you expect a reading of 50mV, set this control to 0.1.

Valid Range:

for Current DC and AC(For EDU34450A model):

0.001, 0.01, 0.1, 1, 3 A

for Current DC and AC(For other models):

0.0001, 0.001, 0.01, 0.1, 1, 3 A

for Resistance 2-wire and 4-wire:

100, 1000, 10000, 100000, 1000000, 10000000, 100000000 ohm

for Voltage DC and AC(For EDU34450A model):

0.1, 1, 10, 100, 750 V

for Voltage DC and AC(For other models):

0.1, 1, 10, 100, 1000 V

for Capacitance(For EDU34450A model):

1 nF,10 nF,100 nF,1 uF,10 uF,100 uF,1 mF,10 mF

for Capacitance(For other models):

1 nF,10 nF,100 nF,1 uF,10 uF,100 uF

Default Value:

for Current DC and AC:

1 - For other models

0.1 - For EDU34450A model

for Resistance 2-wire and 4-wire: 1000

for Voltage AC: 10

for Voltage DC: 1000

for Capacitance : 1uF

Note(s):

(1) This control is only valid if Auto Range is set to Disable.

(2) Setting manual range can improve performance.

(3) Measurements above the manual range value will be returned as out of range.

(4) For Voltage AC and DC, The maximum range parameter is 1000 V, which is set by MAX. However, the SAFETY LIMIT on the front and rear HI/LO input terminals is 750 VAC (rms). The rms voltage is waveform dependent. A sine wave is limited to 750 VAC (rms), but a 1000 Vpk square wave is safe. Connections to AC mains power is further limited to CAT II (300 V). See the "Safety Information" section in this manual for a complete discussion of the safety features and the safe operation of this instrument.

Agilent DMM

Specifies which instrument to use. Instruments that are powered on and connected to your computer are visible in the VISA resource name pull-down menu. Select the resource name from the VISA resource name pull-down menu. If your instrument does not appear in this list, enter the instrument descriptor using the following format:

Interface Type[board index]::Address::INSTR.

Examples:

GPIB: GPIB::22::INSTR, GPIB board 0, primary address 22

TCP/IP Instr: TCPIP::10.0.32.48::INSTR

USB Instr: Selectable from VISA Resource Name pull-down menu

VISA Alias: "SampleInstr" - Alias names are configured in MAX

Refer to the LabVIEW Help for more information about specifying a VISA resource name.

Absolute Resolution (1E-6)

Sets the measurement resolution on the instrument. For example, a value of 0.001 will result in a reading accurate up to the thousandth place.

Valid Range:

for Current DC:

+3.00000000E-07 to +1.00000000E-04

for Resistance 2-wire and 4-wire:

+3.00000000E-04 to +1.00000000E-01

for Voltage DC:

+3.00000000E-08 to +1.00000000E-05

Default Value:

for Current DC: +1.00000000E-06

for Resistance 2-wire and 4-wire: +1.00000000E-03

for Voltage DC: +1.00000000E-07
