Tektronix Scope

VISA Resource Name specifies the instrument to use. You can select any instrument that is powered on and connected to the computer. If the VISA Resource Name list does not include the instrument you want to use, enter the instrument descriptor using the following syntax: Interface Type[board index]::Address::INSTR.

The following list describes different instrument types:

GPIB: GPIB::22::INSTR,which indicates GPIB board 0, primary address 22.

Serial: COM1

TCP/IP Instr: TCPIP::10.0.32.48::INSTR

TCP/IP Socket: TCPIP::10.0.32.45::3800::SOCKET

USB Instr: Select the instrument from the VISA resource name control.

USB Raw: Links VISA to non-USBTMC instruments by using the VISA Driver Development Wizard.

VISA Alias: Configure alias names, such as SampleInstr, in MAX.

Simulate?[Simulate?]

[Simulate?]

Setting this to true will send Simulate=1 to the option string of the initialize VI, telling the driver to use a simulated device instead of the one specified in Resource Name.

If a device is specified in Resource Name and Simulate is set to true, the driver will simulate the module specified in resource name. If Resource Name is left empty, the driver will simulate a PXIe-5105.

The simulated device will output a simulated sine wave.
