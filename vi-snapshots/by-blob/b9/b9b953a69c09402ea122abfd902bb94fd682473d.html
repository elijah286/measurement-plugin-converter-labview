 Scope config

    		Resource name[Resource name]

    Pass the resource name of the NI SCOPE device to initialize.

    To specify multiple devices to be configured in the same session, use a comma between each resource name:

    Dev1,Dev2

    		Scope channel(s)[Scope channel(s)]

    Pass the channel name you want to configure.

    For more information regarding channel names, refer to Channel String Syntax in the NI High-Speed Digitizers Help.

    		Probe attenuation[Probe Attenuation]

    Specify the scaling factor by which the probe you attach to the channel attenuates the input. For example, when you use a 10:1 or 10X probe, set this parameter to 10.0.

    Valid Values:

    Any positive real number. Typical values are 1, 10 and 100.
