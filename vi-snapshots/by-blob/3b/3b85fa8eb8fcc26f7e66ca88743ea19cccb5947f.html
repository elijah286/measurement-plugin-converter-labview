Resolution in Digits[Resolution in Digits]

Resolution in Digits specifies the absolute resolution of the measurement. This parameter is ignored when Range is set to AUTO RANGE ON (-1.0) or AUTO RANGE ONCE (-3.0). The default is 0.001 V

Measurement Type[Measurement Type]

Function - Specify the measurement function used to acquire the measurement. The driver sets the NIDMM_ATTR_FUNCTION attribute to this value.

Device Name[Device Name]

Device Name is the resource name of the device this operation applies to.

Range[Range]

Specify the range for the measurement. Sets the range for the function specified in the Measurement Type control. Range values are coerced up to the closest input range.
