Controls and Indicators

 Sample Rate (S/s)[Sample Rate (S/s)]

Specifies the sampling rate of the NI Signal Generator

FGEN Resource Name[FGEN Resource Name]

Specifies the resource name of the device to open a FGEN session on.

Stop [Stop ]

This button closes the session and stops the VI.

Use this stop button and not the built-in VI Abort button.

Update[Update]

Aborts the generation of the arbitrary waveform and reconfigures the device based on the current values selected for Waveform Information Array, Clock Mode, Sample Clock Source, Sample Rate, Gain, DC Offset, Analog Filter Enabled, and Digital Filter Enabled.

error out

error in can accept error information wired from VIs previously called. Use this information to decide if any functionality should be bypassed in the event of errors from other VIs.

Right-click the error in control on the front panel and select Explain Error or Explain Warning from the shortcut menu for more information about the error.

    		status

    status is TRUE (X) if an error occurred or FALSE (checkmark) to indicate a warning or that no error occurred.
