Agilent 34401 Acquire and Chart - Pretriggered.vi

This example shows how to configure a pretriggered measurement using the low-level Data VIs to retrieve data from the DMM. Measurements are obtained from the instrument's internal buffer and are read iteratively and charted.

Note:

(1) This VI only applies to the Agilent 34411 model.

(2) It is recommended that all triggered measurements be made using an appropriate fixed manual range. That is, disable autorange and manually select a range in Configure Measurement VI.

Front Panel

Controls and Indicators

 Manual Range (1.00)

Sets the range to use on the instrument. Set this to the absolute value of the upper bound of the expected reading and the instrument will adjust to the most sensitive settings that can measure that value. For instance, if you expect a reading of 50mV (.05V), set this control to 0.1 as seen by the Valid Range for DC Voltage below. Any values that are between these ranges will be rounded up to the next range. If a value larger than the biggest range is entered, the biggest range will be selected.

Valid Ranges:

AC/DC Voltage

All models: .1, 1, 10, 100, 1000

2/4 Wire Resistance

Agilent 34401: 100, 1k, 10k, 100k, 1M, 10M, 100M

Agilent 34410/34411: 100, 1k, 10k, 100k, 1M, 10M, 100M, 1G

DC Current

Agilent 34401: 10m, 100m, 1, 3

Agilent 34410/34411: 100u, 1m, 10m, 100m, 1, 3

AC Current

Agilent 34401: 1, 3

Agilent 34410/34411: 100u, 1m, 10m, 100m, 1, 3

Capacitance

Agilent 34410/34411 only: 1n, 10n, 100n, 1u, 10u

Note:

(1) Setting manual range can improve performance.

(2) Measurements above the manual range value will be returned as out of range.

(3) This control is only valid if "Enable Auto Range" is set to "False"

Pretrigger Samples (10)

This control reserves memory for pretrigger samples up to the specified number of sample readings to be taken before the trigger. If the sample count and pretrigger sample count is set to 50000 and 20000 respectively, 20000 samples are taken before the trigger and 30000 samples are taken after the trigger is detected.

Valid Range:

0 to 999999

0 to 10000 (if calculate subsystem is on)

Note:

(1) This control only applies to the Agilent 34411 model.

(2) Pretrigger does not apply to continuity and diode measurements.

(3) When using pretrigger samples, trigger count must be set to 1 and the number of pretrigger samples must be less than the sample count.

(4) It is recommended that all triggered measurements be made using an appropriate fixed manual range. That is, turn autorange off and manually select a range in Configure Measurement VI.

Sample Count (20)

The number of measurements the instrument takes each time it receives a trigger.

Valid Range:

Agilent 34401: 1 to 50000 per trigger (instrument can only hold 512 readings internally)

Agilent 34410: 1 to 50000 per trigger

Agilent 34411: 1 to 1000000 per trigger

VISA resource name

Specifies which instrument to use. Instruments that are powered on and connected to your computer are visible in the VISA resource name pull-down menu. Select the resource name from the VISA resource name pull-down menu. If your instrument does not appear in this list, enter the instrument descriptor using the following format:

Interface Type[board index]::Address::INSTR.

Examples:

GPIB: GPIB::22::INSTR, GPIB board 0, primary address 22

Serial: COM1

TCP/IP Instr: TCPIP::10.0.32.48::INSTR

TCP/IP Socket: TCPIP::10.0.32.45::3800::SOCKET

USB Instr: selectable from VISA Resource Name pull-down menu

USB Raw: You must first link VISA to non-USBTMC instruments by using the VISA Driver Development Wizard

VISA Alias: "SampleInstr" - Alias names are configured in MAX

Refer to LabVIEW online help for more information on specifying a VISA resource name.

Internal Level (0)

This control allows you to trigger on a defined level of the input signal. This command sets the level on which a trigger occurs when the trigger source is set to internal.

Valid Range:

-120% to 120% of the maximum range of the measurement or -120% to 120% of the manually set range.

Default Value:

0%

Note:

This control only applies to the Agilent 34411 model.

Stop

Stops the acquisition.

Function (0: DC Voltage)

Sets the measurement function on the instrument.

Valid Values:

0: DC Voltage

1: AC Voltage

2: 2 - Wire Resistance

3: 4 - Wire Resistance

4: DC Current

5: AC Current

6: Frequency

7: Period

8: Continuity

9: Diode Checking

10: VDC:VDC Ratio

11: Temperature

12: Capacitance

Default Value:

0: DC Voltage

Note:

Agilent 34401 does not support temperature or capacitance configurations or measurements.

Agilent 34410/34411 does not support VDC ratio configurations or measurements.

Trigger Source (0: Immediate)

Sets the source of trigger events.

Valid Values:

0: Immediate

1: Software (Bus)

2: External

3: Internal

Default Value:

0: Immediate

Note:

The internal source is only available to the 34411 model.

Slope (0: Negative)

Selects whether the instrument uses 1) the rising or falling edge of the trigger signal on the rear-panel Ext Trig BNC connector. 2) the rising or falling edge with an internal trigger source.

Valid Values:

0: Negative

1: Positive

Default Value:

0: Negative

Note:

1) This control only applies to the Agilent 34410/34411 models.

2) This control only applies to internal and external trigger sources.

Measurements

Displays measurements returned from the instrument.
