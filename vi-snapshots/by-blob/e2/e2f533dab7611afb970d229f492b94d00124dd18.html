 Frame Sync Clock Control

Contains controls to configure the Frame Sync or Word Select Clock based on the Bit Clock.

    		Frame Length

    Frame Length - Number of bits in a frame.

    		Frame Sync Pulse Width

    Frame Sync Pulse Width - Number of bits for the the frame sync pulse. To configure the frame sync clock at 50% duty cycle, set this value to Frame Length/2.

    		Bit Clock Edge Sync

    Bit Clock Edge Sync - Defines the bit clock edge that alligns with the frame sync clock edge.
