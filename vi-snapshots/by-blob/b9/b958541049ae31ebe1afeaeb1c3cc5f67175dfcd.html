DC POwer T9.lvlib:NI-DCPower Source DC Current T9.vi

Demonstrates how to use the DC Current Output Function to force an output current. This example initializes a session, configures the Output Function, Sense, Autorange, Current Level and Voltage Limit, initiates generation, waits for a specified delay, and measures the voltage and current output. This example uses Single Point source mode.

Source Delay is the amount of time between configuring the output and taking a measurement. The intention is to allow the output to settle before taking the measurement.
