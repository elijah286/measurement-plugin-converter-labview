 System timing config

    		DUT setup time (s)

    		[Source delay (s)]

    Source Delay determines when, in seconds, the device generates the Source Complete event, potentially starting a measurement if the Measure When property is set to Automatically After Source Complete.

    This is intended to allow the output to settle before taking the measurement.

    		[Aperture time (s)]

    Source Delay determines when, in seconds, the device generates the Source Complete event, potentially starting a measurement if the Measure When property is set to Automatically After Source Complete.

    This is intended to allow the output to settle before taking the measurement.

    		[Timeout (s)]

    Timeout (Sec) specifies the maximum time allowed for this VI to complete in seconds. If the VI does not complete within this time interval, an error will be returned.

    This might need to be adjusted depending on the configured number of Points and Plots.
