Physical Channel

Physical Channel(s) specifies the names of the physical channels to use to create virtual channels. The DAQmx physical channel constant lists all physical channels on devices and modules installed in the system.

task out

task out is a reference to the task after this VI runs. The task contains any newly created virtual channels. If you did not wire a value to task in, NI-DAQmx automatically creates the task this output refers to.
