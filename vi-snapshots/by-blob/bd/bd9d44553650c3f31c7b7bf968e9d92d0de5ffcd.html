GetDigitalWaveformData - Copy.vi

Returns the waveform the oscilloscope acquired for the specified channel. The waveform is from an acquisition that you initiate prior to calling this VI.

You use the Initiate VI to start an acquisition on the channels that you enable with the Configure Channel VI. The oscilloscope acquires waveforms for the enabled channels concurrently. You must call this VI separately for each enabled channel to obtain the waveforms.

You can call the Read (Digital Waveforms) VI instead of using low level VIs.

Note This VI does not check the instrument status. Typically, you call this VI only in a sequence of calls to other low-level instrument driver VIs. The sequence performs one operation. You use the low-level VIs to optimize one or more aspects of interaction with the instrument.

You chain instrument driver VIs together by wiring the VISA resource name out terminal to subsequent VISA resource name input terminals.
