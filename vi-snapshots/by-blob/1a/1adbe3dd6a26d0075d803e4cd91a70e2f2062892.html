Operation

task/channels in

task/channels in is the name of the task or a list of virtual channels to which the operation applies. If you provide a list of virtual channels, NI-DAQmx creates a task automatically.

Timing Settings

This cluster consists of elements related to timing settings for clock

    		Sample Clock Source

    Sample Clock Source specifies the source terminal of the Sample Clock.

    Refer to the Device Routes table in Measurement and Automation Explorer to determine eligible sample clock sources.

    		Sample Rate

    Sample Rate specifies the sampling rate in samples per channel per second. If you use an external source for the Sample Clock, set this input to the maximum expected rate of that clock.

    		Number of Samples

    Actual Sample Rate returns the coerced value of the sample clock.

    If using OnboardClock as your Sample Clock Source, your hardware will attempt to derive the sample clock from one of its internal timebases. If it is unable to derive the exact frequency you require, the rate will be coerced.

Trigger Settings

This cluster consists of elements related to trigger settings

    		Digital Start Trigger?

    		Source[Digital Start Trigger Source]

    Digital Trigger Source specifies the name of a terminal where there is a digital signal to use as the source of the trigger.

    Refer to the Device Routes table in Measurement and Automation Explorer to determine eligible trigger sources.

    		Edge[Digital Start Trigger Edge]

    Edge specifies on which edge of the digital signal to start acquiring or generating samples.

Channel Settings

This cluster consists of controls related to Channel settings

    		Current Setpoint

    Current Setpoint specifies the output current, in amperes.

    If the load draws current exceeding this specified value, the device will operate under Constant Current mode.

    		Voltage Setpoint

    Voltage Setpoint specifies the constant output voltage, in volts.
